Прототипы страниц ADDU

Страницы собраны из единого набора сквозных блоков (hero → кейсы с метриками → боли → что входит → тарифы → этапы → сравнение → definition → цифры → FAQ → CTA). Структуры — из конкурентного анализа (research/competitors/) и реверс-инжиниринга запросов (P01). Цены и кейсы, помеченные «макет», требуют данных партнёров/ADDU.

Собрано

Продвижение на Авито →

Приоритет №1 по созвону. Полная структура: 13 блоков, включая квиз-расчёт (ниша, свободная у всех 8 конкурентов), definition-блок про авитолога и SEO-слой «платное vs бесплатное».

Фирменный стиль →

Первая страница дизайн-блока (названа на созвоне). Собрана из ТЕХ ЖЕ блоков, что Авито, — доказательство сквозности шаблона. Пакеты «Логотип / Фирстиль / Брендбук» по вилке рынка.
